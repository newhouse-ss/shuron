**比较口径：**
- 四子类型、严格匹配、valid100：只和主论文比（0.73 / 0.76）。
- 单一类型：和 NEEDLE 0.9228、BioBERT 0.8971 比，注明划分不同。
- 增益只在同一个模型内部比较。

**不主张：**
- LLM 可以替代独立标注者；
- 方法在绝对分数上胜过主论文。

**讨论（不做实验）：** 数据集达到一定规模后，转用监督学习。

English (for slides):
- Focus: In the low-resource stage, help experts build a dataset that meets expert standard with less work, using LLM pre-annotation.
- Goal 1 (quality): How far LLM pre-annotation is from expert annotation, and whether guideline refinement narrows the gap.
- Goal 2 (burden): At expert standard, how many corrections experts still make compared with annotating from scratch.

**论点 2、3 的两项探索：**
- **对照组：** 主要结果复现中同一方法的 5 个循环。基础方法（top-1 或 top-4）由复现结果决定。
- **比较方式：** 5 对 5，只改一个变量。
- **"含目标错误簇的文档"：** 指开发文档中正确标注了本轮目标错误簇的 gold 类型的那些文档，按数量排序取前 5 篇；不足 5 篇时，按原来的顺序补齐。
- **标注理由：** 只有多标、类型错和边界错这几类错误有理由可传；漏标没有。
