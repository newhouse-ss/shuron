# 指南优化 研究方向 与实验计划

2026-10-19。面向 2026-10-20 四人研究讨论。本文依据中期摘要与 slides、基础论文、本地实验记录及公开一手文献。原会议材料和 proposal 均保留。本轮没有启动付费实验。

## 1. 对当前研究和原 proposal 的判断

**研究问题有价值，原 proposal 的候选方向也有依据，但不宜按原来的多臂完整循环直接执行。** 当前更缺的是对已有结果的完整评价、清楚的监督边界，以及一个能说明为什么有效的主要对照。把模型迁移、三次接受判定、动态示例、gold 注入、冲突修复和第二模型 reviewer 同时展开，成本很高，而且可能仍然无法解释哪项变化产生了收益。

长期目标保持不变：在少量人工标注条件下提高新文档的标注质量，逼近可比的强基线，再判断能减少多少专家工作。本阶段不能用一个来源不清或口径不一致的 F1 数字代替这个目标。

建议优先顺序是：

1. **先补证据。** 审计和补评已经生成的 Top-1、Top-4 重复轨迹终版，避免只根据最成功的一条决定下一阶段。
2. **再选一个方法。** 按用户已确认的边界，writer 只接收抽象信息。优先试验“抽象防回归条件能否替代实体级保护示例”，先小样本机制试验，通过后再开展完整循环。
3. **保留一个追求性能的备选。** 类型和边界错误有较大可修复空间，可以试验权限明确的类型复核或边界复核，但不预设 reviewer 一定有效。
4. **最终检验独立进行。** 当前 valid100 已参与方向选择。需先确认原始 test 是否真正未参与开发，再冻结最终检验。

这些是按证据、信息价值和成本排序的建议，不是已测得的 ROI 倍数，也没有可据以预测的未来 F1 增益。

## 2. 从中期发表延续下来的问题

两版中期摘要第 1 页 Table 1 提出六项诊断，构成三个研究轴：提取有效规则、泛化到新文档、可靠评价。这比单个冲突案例更接近课题的完整范围。

| 中期问题 | 现在掌握的证据 | 尚未证明什么 |
| --- | --- | --- |
| 保护正确案例的示例进入指南 | 中期新增行中 38/52 可追溯至五篇示例；后续发现点名排除也来自这些文档 | 文本重合不等于有害记忆，也未证明复制导致全部泛化差距 |
| 示例不随错误类型变化 | 前五篇至少有 TP 的文档经常固定，目标错误变化时保护材料未变 | 按错误动态选择是否改善新文档质量 |
| rationale 没有被利用 | 标注器可以输出解释和引用章节，迭代流程没有充分利用 | 解释是否忠实、是否比直接错误信号更有用 |
| dev10 覆盖不足 | 中期 Modifier 漏标在 dev 与 valid 分布不同 | 覆盖选择优于随机选择，或增加文档本身必然有效 |
| 单次评价不稳定 | 重复标注波动、非目标预测不复现、接受决定敏感 | 某个重复接受策略能改善最终质量 |
| 单簇修改造成副作用 | Top-4 有积极的单轨迹 valid 观察，也存在未达开发阈值的重复运行 | Top-4 稳定优于 Top-1，或更多簇总是更好 |

中期去除 verified examples 后，文本复制减少，但没有达到 dev F1 0.9。禁止复制也没有解决问题。因此，“去掉实体示例”是用户监督边界下必须面对的设计条件，并非已经证明有效的改进。真正值得问的是，能否用抽象规则保留示例原本的防回归作用。

来源为两份摘要第 1 至 2 页，以及两份中期 slides。新版 slides 第 10 页写出约 .79 逼近 .87、保留 10 篇监督优势的目标；该 .87 未在本轮找到同口径的直接来源。

## 3. 当前结果应如何汇报

### 3.1 这是历史观测表，尚非同期完整方法比较

| 指南来源 | strict span＋subtype F1 | exact span、忽略子类型 F1 | 主要限制 |
| --- | ---: | ---: | --- |
| 原指南 | 0.7792 | 0.8351 | 8 月批次 |
| Top-1，dev10 | 0.7878 | 0.8490 | 单条轨迹，8 月评价 |
| Top-4，dev10 | 0.8023 | 0.8546 | 单条已评分轨迹，10 月补评 |
| Top-1，dev30 | 0.8050 | 0.8455 | 单条轨迹，监督文档更多 |

strict 指边界和四种子类型同时正确。相同 GPT-5.4 部署名称不保证跨月模型版本相同，不能把这张表说成同期完全受控对照。

Top-4 相对 Top-1 的观察差为 +0.0145，现有文档配对 bootstrap 区间为 [-0.0209, +0.0498]，包含零。这支持继续验证，尚不支持“显著且稳定提升”。其余三条 Top-4 轨迹开发终点为 .8252/.8552/.8841，未测 valid，不能仅凭未达 .9 判断其泛化无效，也不能忽略。

规模实验 valid F1 .7878/.7745/.8050 非单调。实体字符串吸收率约 41%/9%/3% 单调下降，不能据此推导泛化单调改善。BC5CDR 原指南/修改后 .8634/.8579，BioRED .7836/.8077，也说明收益有条件；这些使用 GPT-5.2，不能把跨语料差异完全解释成数据集差异。

### 3.2 一个会改变方向排序的分类细节

Top-4 有 629 个 TP、148 个 FP、162 个 FN，预测 777 个，gold 791 个。TP 是完全正确实体，FP 是多出的错误预测，FN 是没有正确恢复的 gold。分类脚本产生 208 条错误记录，其中一条类型或边界错配会同时贡献一个 FP 和一个 FN，208 不是 FP＋FN。

| 分类 | 数量 | 正确解释 |
| --- | ---: | --- |
| 同跨度、不同类型 | **41** | 固定跨度时可单独研究的类型错误 |
| 类型和边界同时不同 | **16** | 被脚本优先归入 label_mismatch，不能算纯类型错误 |
| 同类型、不同边界 | 45 | boundary_mismatch |
| 没有重叠预测的漏标 | 55 | Modifier 27、DiseaseClass 25、SpecificDisease 3 |
| 没有重叠 gold 的误报 | 45 | 其中 SpecificDisease 28 |
| 未配对重叠 | 6 | 5 条 gold、1 条预测，需要单独保留 |

**原 proposal 的“57 个类型错误全部修复后 F1 .8750”包含了 16 个同时修正边界的案例。** 该模拟替换了整个答案，不能据此说“只做子类型复核就能达到 .875”。固定预测跨度的理想类型修正参考是 .8546，而非 .8750。它仍只是理想化参照，不是实际 reviewer 的预期结果。

SpecificDisease 与 DiseaseClass 在 label_mismatch 中各有 21 次相反方向混淆，但其中可能同时存在边界变化。对称计数不是 gold 歧义证据。应先按同跨度与不同跨度分开审查，再讨论类别定义、模型误判或标注不一致。

### 3.3 FALDH 证明了什么

R4 原则单独使用时，3/3 被识别为疾病，但类型和跨度并非全部严格正确；完整 R4 指南下 0/3；删除三处点名排除后 3/3 严格恢复。R3 删除其两处点名排除后仍为 0/5。结果支持在这些条件下，R4 新增内容与排除删除共同发挥作用，不能唯一定位哪一句，也不能直接外推到所有漏标。

R4 和 R3 删除实验跨日进行，模型版本信息也有限。点名字符串未出现在 valid100，局部修复不直接支持整体 valid 提升。

“R4 被噪声接受”也需收紧。把两个不能复现的预测替换后，保持其他预测不变得到 .8811，低于 R3 的 .8873；这是反事实计算，不是完整 dev 重标均值。最准确的结论是：**原接受决定对不能复现的预测敏感，随机性和部署变化尚未被完全分离。**

## 4. 原方法的信息传递问题，比“不给 gold”更具体

源码 `_build_true_positive_examples` 给 writer 展示完整文档及每篇最多五条严格核验的 TP，共取前五篇至少有一个 TP 的文档。列表既不是完整 gold，也不是完整预测。某个短语不在列表中，可能是漏标，也可能仅因截断而未列出。

因此，不能笼统说 writer 从未收到任何 gold 信息。准确说法是：它收到**由 gold 核验的部分正例**，却没有目标漏标的答案和完整标注，提示又把这些 examples 统称为正确处理。部分正确性证据可能被误读成完整文档的正负判断，这是有依据、尚待受控验证的机制假设。

基础论文 §3 描述 writer 会接收 discrepancy context 及 sampled verified TP；当前实现的实际字段和固定示例选择与论文文字之间存在差异，应请作者确认哪些是预期行为。修复实现的信息遗漏不自动构成新方法，贡献需要落在可复用的约束、受控证据和新文档表现上。[基础论文](https://aclanthology.org/2026.acl-long.1760/)

**用户已确认的新边界是：开发 gold 可用于上游错误分析和评分，writer 只接收抽象原则，不接收实体级答案。** 因此新方案不能继续把原方法的 TP 答案列表交给 writer，也不能默认直接注入目标 gold。整个系统仍使用开发监督，不能称为完全 gold-free。

## 5. 文献中哪些证据真正相关

以下覆盖直接前置研究、NER 的规则与示例方法、自动提示优化及复核评价。它们的任务、模型和监督量不同，数值只说明原研究结果，不是本项目增益预测。

| 一手研究 | 已有证据 | 对本项目可用的结论及边界 |
| --- | --- | --- |
| Kim、Kim、Aizawa，ACL 2026，[Refining and Reusing Annotation Guidelines](https://aclanthology.org/2026.acl-long.1760/) | 10 篇训练文档 refinement、100 篇原开发文档评价；NCBI GPT-5 三种条件 F1 .46/.73/.76，Table 1 | 直接前置方法；提升有限且可能引入 FP。三个数是条件 F1，不是 P/R/F1 |

| Pryzant 等，EMNLP 2023，[ProTeGi](https://aclanthology.org/2023.emnlp-main.494/) | 文字错误反馈、候选改写、搜索与选择 | 自动迭代改写已有先例；完整搜索会加重十篇 dev 上的选择偏差 |
| Opsahl-Ong 等，[MIPRO](https://arxiv.org/abs/2406.11695)；Agrawal 等，[GEPA](https://arxiv.org/abs/2507.19457) | 多阶段指令/示例优化，以及反思驱动候选演化 | 作为方法定位有用；缺本任务直接证据，不列本期优先实现 |
| Huang 等，ICLR 2024，[无外部反馈的推理自纠错](https://openreview.net/forum?id=IkmD3fKBPQ) | 特定推理任务中，自纠错可能失败或变差 | 支持统计 fixes/breaks 和设置公平对照；不证明跨模型 biomedical NER 复核无效 |
| Geifman、El-Yaniv，[Selective Classification](https://arxiv.org/abs/1705.08500)；Lingren 等，[预标注对人工工作的研究](https://academic.oup.com/jamia/article-pdf/21/3/406/9517677/21-3-406.pdf) | 前者讨论风险与覆盖率，后者直接研究人的标注过程 | “让多少文档转人工”和“剩余多少错误”应同时报告；省时结论需要真实人的测量 |

文献没有给出一个能直接搬来、保证将本项目 .80 提升到 .90 的方案。最接近本项目的研究仍显示方法依赖于反馈质量、规则整合、任务定义和评价设置。

## 6. 候选方向的优先级

| 方向 | 推荐级别 | 为什么值得做 | 最便宜的反证或停止条件 |
| --- | --- | --- | --- |
| 补评现存 Top-1/Top-4 轨迹 | **先做的信息补全** | 已有指南，省去重新生成；能检查成功轨迹是否有代表性 | 重复轨迹不支持收益时，停止把单次 Top-4 当作稳定提升 |
| 抽象防回归条件替代实体示例 | **主要方法候选** | 直接回应用户边界和去示例后的既有负结果；保留“保护正确行为”的功能 | 抽象条件无法同时表达正确行为与例外，或目标不改善、回归增加，则不扩完整循环 |
| 写后冲突审查 | **先作为开发诊断** | 本地规则冲突证据直接，GuideNER 提供相关先例 | 在已有正反案例上误报多、漏报多，则不能自动修复。若反馈 writer，仍只给抽象信息 |
| 类型/边界分开的复核 | **性能备选** | 41 个纯类型、16 个混合、45 个纯边界，错误空间值得针对性试验 | dev 净修复不超过破坏则停止。不能拿 .875 当纯类型上限 |
| 按错误模式选择证据 | **抽象教师端备选** | 中期已提出，检索文献有间接动机 | 新边界下不能把实体级正反例发 writer；只能先在原十篇归纳抽象条件 |
| 重复测量与稳健接受 | **共同测量优先，策略另测** | 有决策敏感性证据 | 不能先验宣称三次接受法更好，更不能让所有改动共享未经验证的新优越基线 |
| 廉价模型替代 | **条件性成本工具** | 可能支持更多重复 | 只测原指南相近不足；需对长指南和方法对比做桥接，结论先限定新模型 |
| 覆盖平衡的十篇开发集 | **后备** | 可能改善错误类型覆盖 | 使用全训练 gold 选十篇会超出十篇监督；不以 random20/30 结果支持其有效性 |
| rationale、指南压缩、外部知识检索 | **后备** | 可针对解释丢失、指南膨胀及知识错误 | 缺当前瓶颈直接证据；知识检索不一定解决数据集类型和边界约定 |
| 八模型分歧、全面 prompt search、其他语料同步铺开 | **本期不优先** | 有相关方法，但成本和解释负担大 | 没有本地小试证据前不扩展 |

这里“主要方法候选”的机制依据强于其全局性能证据。若小试只改善 FALDH 等开发案例，应如实形成机制结果，再转向类型/边界备选；不能为维持原假设不断扩大实验。

## 7. 对原 proposal 的具体修改

| 原设计 | 修订及理由 |
| --- | --- |
| 四五臂完整循环，加 reviewer | 收窄为一个主要 A/B 对照，设阶段门；其他方向列替代路线 |
| writer 直接接收目标 gold | 删除，按已确认边界改为抽象原则及抽象保护条件，连既有 TP 答案列表也不发送 |
| .012 当接受改善门槛 | 它约为两个三次均值差的一个标准误，不是 95% 显著性门槛；若保留只能叫工程阈值并另验证 |
| 三轨迹加文档 bootstrap 即覆盖全部噪声 | 分开固定指南标注、指南生成轨迹、有限文档三层变异；bootstrap 是给定指南和预测的条件性评价 |
| 每个终版都看 valid，然后称独立验证 | valid100 已用于开发决策，承认其角色；保留未使用 test 做冻结后的确认 |
| 对称类型混淆可能就是 gold 问题 | 只能列假设，先区分同跨度与混合错误，再按上下文独立审查 |
| 零冲突、复制比例不升也是硬成功条件 | 扫描器不完备，文本吸收不是泛化代理；改为辅助诊断，主要看质量和回归 |
| 原指南分数接近即可改换模型 | 同期评价多个指南及错误结构；不把旧 GPT 结果与新模型结果直接当主对照 |
| reviewer 与 .961 的差是人工剩余工作 | 删除该解释。比较相同权限的复核，另做明确的选择性复核模拟或真实人工测量 |

0.9606 的计算为 731 TP、0 FP、60 FN，建立在现有匹配及编辑规则上。它遗漏未配对重叠的可能恢复，也禁止新增；允许新增的 reviewer 权限更大。因此将其改名为“规定 gold 编辑操作下的模拟分数”，不用“专家上界”。

## 8. SOTA、十篇监督与订阅问题

NCBI 官方原始语料有 793 篇摘要，训练/开发/测试为 593/100/100。四种标签和不同转换版本需要核对。593 是原始训练集规模，不是证明“所有微调方法必须标 593 篇”，也不等于已测得的人工节省。[官方资源](https://www.ncbi.nlm.nih.gov/CBBresearch/Dogan/DISEASE/)，[语料原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC3951655/)

BioBERT 原论文 Table 6 的 NCBI 89.71 来自 v1.1 (+PubMed)、BERT Base、单 Disease 类型的实体匹配，且做了去重预处理；不能把它写成 BioBERT-Large v1.2 的原始成绩。[BioBERT](https://pmc.ncbi.nlm.nih.gov/articles/PMC7703786/) Zhao 与 Goto Table 4 的 .897 是另一份实验说明，应独立引用。[该论文](https://arxiv.org/html/2503.03261v2)
