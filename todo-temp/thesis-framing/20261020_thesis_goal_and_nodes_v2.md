**这对目标意味着什么：**
- **0.86 不是 NCBI 的数字。** 它对应的是 BC5CDR：主论文的 moderated 分数是 0.86，Zhao and Goto (2025) 的 BC5CDR-Disease 是 0.866。
- **NCBI 的 SOTA 是 0.9228，只有单一类型的版本。** 四子类型的监督结果没有人发表过。
- **子类型修正对 SOTA 差距没有帮助。** 单一类型评分不看子类型。

## 2. 修改后的目标

**总目标：** 改进 guideline refinement，减轻人工标注负担。

**三个研究问题：**

| 名称 | 问题 |
| --- | --- |
| 诊断 | refinement 带来的收益为什么小，而且不稳定？ |
| 修正 | 针对失败点做修正，能不能消除目标错误、又不带来回归？增益有多大？ |
| 定位 | 离主论文和监督 SOTA 有多远？要达到给定水平，还需要人工检查多少？ |

**贡献：** 有对照实验支撑的失败点诊断；每个修正各自测出的增益；三种口径的比较基准；能在标注噪声下判断增益的评价方法。

**不主张：** LLM 标注可以替代专家标注；我们的方法在绝对分数上优于主论文的方法。

### 2.1 三种比较口径

| 口径 | 怎么算 | 和谁比 |
| --- | --- | --- |
| 主论文口径 | 四子类型，严格匹配，valid100 | 主论文 GPT-5：原指南 0.73，moderated 0.76 |
| 单一类型口径 | 把四个子类型合并成一个类型，valid100 | NEEDLE 0.9228、BioBERT 0.8971。他们评在测试集上，所以要注明划分不同 |
| 测试集口径 | 单一类型，官方测试集，只用一次 | 同上，这次在同一划分上比 |

我们的数据换算到 SOTA 口径时，能换算什么：

| 不同之处 | 处理 |
| --- | --- |
| 标签：四子类型 vs 单一类型 | 换算。已经算过：原指南 0.8351，R4 0.849，top-4 0.8546 |
| 划分：valid100 vs 测试集 | 换算不了，只能靠"测试集评价" |
| 预处理：文档级 PubAnnotation vs 句子级 BIO | 差别小，不换算，写明即可 |
| 监督量：10 篇 vs 593 篇加弱标签 | 不换算，这正是比较要说明的东西 |

主论文的分数目前只能放进主论文口径，因为官方仓库里没有它的预测结果。如果 PubAnnotation 上的 "ncbi-valid-…" 项目能确认是主论文的标注，就可以把它也换算成单一类型。

### 2.2 怎么看增益

- **方法的证据：** 只看同一个模型内部的增益，比如有没有这个修正、改进后对原指南。文档和评分器固定，附上区间，主论文口径和单一类型口径都要报。
- **和主论文比：** 两边的增益并排列出，只作描述，不下结论。
- **跨模型的稳健性：** 同一个增益在 GPT-5.4 和 DeepSeek 上都成立，才算稳健。
- **绝对分数：** 只用来回答"定位"问题，不用来证明方法有效。
- **模型版本不需要和主论文统一，而且也统一不了。** 主论文 GPT-5 的具体版本没有记录；DeepSeek 现在同一个模型名背后已经是 V4.1。能做的是每次调用都保存 `model` 字段。

同一个增益，换个口径数值就不一样：

| 相对原指南（GPT-5.4） | 主论文口径 | 单一类型口径 |
| --- | --- | --- |
| R4 | +0.0086 | +0.0139 |
| top-4 | +0.0231 | +0.0195 |

单一类型的区间还没算。子类型修正的增益，在单一类型口径下是 0。

**幻灯片用的英文版本：**
- Goal: Reduce the burden of human annotators by improving LLM guideline refinement.
- Contribution: Identify the failure points of the refinement loop, fix them, and measure each gain within one model under annotation noise.
- Scales: base-paper scale (four subtypes, strict, valid100); one-type scale (valid100); one-type scale on the test split, used once.
- Not claimed: LLM annotation replacing expert annotation.

## 3. 为什么要改

1. **目标数字的口径是错的。** 0.86 对应的是 BC5CDR。NCBI 的 SOTA 是 0.9228，而且只有单一类型的版本。
2. **按现在的目标，论文的结论只能是"没达到"，而且"提升没被证实"。** 反过来，诊断部分的结果是清楚的。
3. **导师和两位副查已经指向这个改法。** 9/15 的计划也已经写下来，只是三个记录文件没有同步。
